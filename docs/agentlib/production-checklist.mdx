Review these settings before you run agents in production:

- Set timeouts on model calls.
- Use [lazy state](/agentlib/sessions#lazy-state) for long conversations.
- Set the [inactivity timeout](/services/configuration#timeouts).
- Check the defaults for some importnat settings: set compaction, maxSteps, maxToolCalls,
